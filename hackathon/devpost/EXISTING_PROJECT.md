# Existing project declaration

Ultra Cards extends a personal greeting-card concept and the initial Ultra Cards studio. The repository's first code commit, `fbb58f0`, is dated November 2, 2026. It documents 240 design combinations, a free card editor and sharing. There is no repository evidence of pre-October 1 Ultra Cards implementation. Earlier personal cards were inspiration. The owner should verify the separate projects' timeline before making any declaration about them.

The hackathon revision adds a larger studio catalogue, private account integration, Gemini assistance, PayPal sandbox payment verification, per-card premium access and server-published recipient snapshots. See [the changelog](../../docs/HACKATHON_CHANGELOG.md).
